# theme-report

휘휘의 주식 테마 리포트 저장소입니다.

## 이 저장소에 있는 것

| 파일 | 설명 |
|---|---|
| `index.html` | 오늘의 테마 리포트 (상승·하락 테마, 지수, 수급, 매매 체크포인트) |

## 보는 방법

- **GitHub에서:** `index.html`을 누르면 코드가 보입니다. (아직 웹페이지 모양으로는 안 보임)
- **웹페이지로 보기:** 2단계에서 GitHub Pages를 켜면 인터넷 주소로 볼 수 있습니다.
